  • Baseline: 0 (sample 500 leads récents)

  • 1 contenu solide / semaine (process 21, no light-skip 12–15)
  • Report lundi → Slack C0BLRUTQJT1
  • Taux d’approbation draft↑ · rework visuel↓
  • Autonomie progressive (gates retirables avec preuves)

Leading (pas la vérité business)

  • GSC: clics, impressions, CTR, position (URLs publiées)
  • Publish on-time
  • Items stuck in review

3. Evaluate — gap & jugements

Métriques

  • Gap business = 10 − leads_organo_mois (auj. ≈ 10)
  • Gap ops = retards publish, rework visuel, items bloqués gate
  • GSC Δ 7j sur URLs du loop

Rubrics / checks

  • QA article: SEO+GEO+UTM+claims datés
  • QA visuelle: alignement, images, preview≈prod
  • Policy: 974 only, pas KAP, pas € orphelins
  • Gate: jamais skip humain v1

Juge

  • Agent: scoring / checklist entre gates
  • Erwan: sujet, draft+preview, publish
  • Déterministe: UTM présents? step 12–15 complete?

4. Act — actions bornées

Contenu (1 prioritaire/sem)

  • Research 01–07 si refresh dû
  • Draft pack 08–11 → gate
  • Après approve: 12–15 complets
  • 16–18 intégration code (pas deploy)
  • Après publish gate: 19–21

Mesure / notify

  • Snapshot hebdo GSC+Velora+pipeline
  • Report Slack lundi
  • Escalade si gate > 7j

Interdit

  • Publish/deploy sans gate
  • Light-skip 12–15
  • KAP / hors 974 / € non datés

6. Decide — continue / stop / change / escalate

Continue

  • Finir l’item en cours avant d’en ouvrir un autre
  • Enchaîner l’étape suivante si checks OK
  • Boucler la semaine suivante

Stop / pause

  • Publish sans gate tenté
  • UTM pipeline cassé après “fix”
  • Rework visuel répété sans patch skill
  • Crédits OpenSEO dead sans fallback

Change strategy

  • Mensuel: keep / improve / kill sujets
  • 90j: assouplir gate draft si preuves
  • Prioriser clusters GSC qui bougent

Escalate → Erwan

  • Gate ouverte > 7 jours
  • ≥3 rejects visuels d’affilée
  • GSC vide 2 semaines
  • Ambiguïté policy / claims
